## 1. Vision

EduCore is a **premium, modern School Management SaaS** designed for K-12 schools that want clarity, speed, and professionalism.

We are building a product that feels like **Stripe + Linear + Notion** — calm, beautiful, and extremely effective.

## 6. UI/UX Guidelines (Strict)

We follow **elite SaaS standards**:

- Use **Geist** font family
- Maximum **3 font weights**
- Generous whitespace
- Rounded corners (16px–24px)
- Subtle shadows only
- High contrast text
- Mobile-first responsive
- No clutter, no unnecessary icons

**Reference products**: Stripe, Linear, Vercel, Notion, Framer.

---

## 7. Technology Decisions (Locked)

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS + minimal custom CSS
- **Database**: Prisma + PostgreSQL
- **Auth**: Supabase (or NextAuth)
- **Components**: Server Components + Client where needed
- **Logo**: Pure SVG (no images)
